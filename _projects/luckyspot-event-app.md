## Problem

Popular events reward whoever clicks fastest. LuckySpot gives everyone a fair chance by lottery.

## What I did

- **Built features in Java** across entrant, organizer, and admin user stories.
- **Integrated Firebase** Authentication and Firestore.
- **Delivered in Agile sprints** with GitHub CI, UML, storyboards, and mocked unit tests.
